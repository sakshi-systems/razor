# razor

Бритва: агент, который читает проект — доки, артефакты, код — и спрашивает о каждой вещи, должна ли она существовать и можно ли сделать её проще. В проекте ничего не пишет; здесь хранит, чему научилась на каждом проекте. Правила — в `CLAUDE.md`.

Начало: открой агента в этом репозитории — при первом входе он спросит, какой проект смотреть.
